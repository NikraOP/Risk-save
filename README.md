# Редактор сохранений Risk of Rain 2

Открывает и закрывает персонажей, уровни Затмения, навыки, скины, предметы, снаряжение, артефакты, записи логбука и достижения. Ещё можно менять лунные монеты. Списки выгружены прямо из игры версии 1.4.1 со всеми DLC, названия на русском и английском.

## Как пользоваться

**С автопоиском (Windows, нужен Node.js):** запусти `start.bat`. Редактор сам найдёт профили в папке Steam, откроет выбранный и при сохранении запишет его на место. Перед записью старая версия кладётся в `backup/`.

**В браузере:** открой сайт, выбери файл профиля из
`C:\Program Files (x86)\Steam\userdata\<ID Steam>\632360\remote\UserProfiles`,
внеси правки и нажми «Сохранить». Скачанным файлом замени старый.

Перед правкой закрой игру: при выходе она перезаписывает профиль.

## Важно

- Если достижение есть в профиле, игра при входе заново выдаёт его награду. Поэтому, когда закрываешь открытие, редактор убирает и достижение, которое его даёт.
- Персонажи из DLC играбельны, только если DLC куплено. Флаги в сохранении этого не меняют.

## Данные

`data/game-data.json` — выгрузка из игры, `data/icons-*.png` — иконки. `node tools/build-data.js` собирает из них `data/game-data.js`.
